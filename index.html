Tentang export ke Google Sheets: file di bawah diunduh dalam format CSV yang langsung bisa dibuka Google Sheets. Cara tercepat: buka sheets.new → File → Import → Upload → pilih file CSV ini → "Replace current sheet". Laporan berikutnya cukup diimpor ulang dengan cara yang sama untuk memperbarui data.

Tentang penyimpanan data: versi ini menyimpan data langsung di browser kamu (localStorage), jadi datanya khusus untuk perangkat & browser yang dipakai — bukan tersinkron ke cloud. Lakukan export CSV secara rutin sebagai backup, terutama sebelum membersihkan cache browser.
